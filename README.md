# MoneyTrail 💰

A simple, lightweight pocket ledger app for tracking income and expenses. Dark theme with green/red color-coded amounts.

## Features

✅ **Add Transactions** - Quick entry for income and expenses
✅ **Dark Theme** - Easy on the eyes
✅ **Color-Coded** - Green for income, red for expenses
✅ **Filter Transactions** - View all, income only, or expenses only
✅ **Real-Time Balance** - Instant calculation
✅ **Local Storage** - All data stays on your device (no cloud sync)
✅ **Simple & Clean** - No clutter, no ads, no sign-ups

## Deployment

### Option 1: GitHub Pages (Free, Hosted)
1. Go to your repository settings
2. Navigate to **Pages** section
3. Select `main` branch as source
4. Your app will be live at `https://mytonite86-coder.github.io/MoneyTrail-`

### Option 2: Netlify (Free, Easy)
1. Connect your GitHub repository to Netlify
2. Netlify auto-deploys on every push

### Option 3: Mobile App
1. Install **Capacitor**: `npm init @capacitor/app`
2. Add iOS/Android platforms
3. Build and deploy to App Store or Google Play

## Usage

1. **Add Entry**: Fill in description, amount, and type (income/expense)
2. **Filter**: Click filter buttons to view specific transaction types
3. **Delete**: Click trash icon to remove an entry
4. **Balance**: Check real-time balance in header

## Tech Stack

- **HTML/CSS/JS** - Vanilla JavaScript (no dependencies)
- **Tailwind CSS** - Utility-first styling
- **LocalStorage** - Client-side data persistence
